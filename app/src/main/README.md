# FleetDZ GPS
تطبيق أندرويد لتتبع شاحنات تعاونية الحبوب والبقول الجافة وسط، يعرض https://www.fleetdz.com/map

## الميزات
- أيقونة تكيفية (Adaptive) + شاشة بداية بهوية التطبيق
- سحب للأسفل للتحديث، شريط تحميل، شاشة "لا يوجد اتصال"
- زر الرجوع يتنقل داخل الموقع، والروابط الخارجية تُفتح في المتصفح

## الحصول على APK
1. ارفع كل الملفات إلى GitHub (فرع `main`).
2. تبويب **Actions** ← **Build Android APK** ← انتظر الاكتمال.
3. نزّل `FleetDZ-APK` من **Artifacts**، فك الضغط، وثبّت `app-debug.apk` على الهاتف
   (فعّل "السماح بالتثبيت من مصادر غير معروفة").

أيقونة 512×512 جاهزة في `store/icon-512.png`.
